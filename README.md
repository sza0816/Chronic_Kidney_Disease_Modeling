# Chronic_Kidney_Disease_Modeling

This is a group project in R exploring key factors affecting a patient's risk of developing the chronic kidney disease and building models to distinguish CKD patients and healthy human objects. The dataset comes from the UC Irvine Machine Learning Repository. It was collected in Apollo Hospitals in Tamil Nadu, India in 2015.
